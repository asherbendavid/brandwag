# Brandwag

Fixed-location weather monitoring app for a farm. Two jobs:

1. A daily weekday morning heads-up on heat and rain, ahead of the morning meeting.
2. A burn-day wind alarm — when armed, watches for wind gusts that would make an
   already-approved burn unsafe, and raises a real alarm (not just a notification) if
   conditions turn.

Also shows a scrollable stack of daily forecast cards on the home screen.

Built on [Open-Meteo](https://open-meteo.com/) forecast data and
[Meteocons](https://meteocons.com/) icons. See `REQUIREMENTS.md` for the full
requirements and `ATTRIBUTIONS.md` for third-party credits.
